# Pandas With Data Science — MovieLens 20M Dataset

## 📌 Project Overview

This project is a hands-on Data Science practice project focused on using Python and Pandas to work with large-scale real-world datasets.

As part of this learning journey, I worked through Step 44 of the "Pandas With Data Science.AI" Kaggle Notebook and analyzed the MovieLens 20M dataset.

The main focus was understanding how Pandas can be used to inspect, clean, transform, filter, aggregate, and analyze large tabular datasets.

## 📊 Dataset

The project uses the MovieLens 20M dataset.

The ratings dataset contains more than 20 million user-movie rating records, providing practical experience working with a large-scale dataset.

Dataset / Kaggle Notebook:
https://www.kaggle.com/code/harunshimanto/pandas-with-data-science-ai
